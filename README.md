# Project & Task Management Data Analysis

## Overview
This project analyses project and task management data using Excel and SQL.

## Tools Used
- Microsoft Excel
- SQL Server
- SQL Server Management Studio (SSMS)

## Dataset
The dataset contains project and task information including:
- Project Name
- Task Name
- Assigned To
- Start Date
- Days Required
- End Date
- Progress

## Analysis Performed
- Project-wise task analysis
- Project-wise average progress
- Task status classification
- Pending task analysis
- Employee-wise workload analysis
- Employee-wise average progress
- Project-wise employee workload
- Project-wise status breakdown

## Excel Dashboard
The Excel dashboard includes:
- Total Projects
- Total Tasks
- Completed Tasks
- Pending Tasks
- Average Progress
- Project-wise task chart
- Project-wise average progress chart
- Task status distribution
- Employee-wise workload
- Interactive slicers

## SQL
SQL Server was used to perform data analysis using:
- GROUP BY
- COUNT
- AVG
- CASE WHEN
- TRY_CONVERT
- REPLACE
- ORDER BY
- Filtering and aggregation

## Project Files
- `Project_Task_Analysis.sql` — SQL analysis queries
- Excel dashboard — Project and Task Management Dashboard

## Key Outcome
The analysis helps understand task distribution, project progress, pending work and employee workload.
